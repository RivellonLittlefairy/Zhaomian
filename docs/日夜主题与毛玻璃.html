界面与操作

  • 顶部仅保留标题和统一线条风格的太阳 / 月亮图标，移除额外的运行状态文字与信息入口。图标切换日间 / 夜间，选项保存在本地，首次默认夜间。
  • 主题覆盖监控、相册、规则三个页面，系统状态栏图标颜色随之调整。
  • 切换主题不重建 PreviewView、不重新绑定相机或模型，检测会继续运行。
  • 检测状态移出画面，放在上方紧凑信息栏，右侧显示实际处理帧率（FPS），按检测完成时间计算，未运行或尚无有效采样时显示 — FPS。
  • 预览填满剩余可用区域，不再居中放置固定 3:4 画面造成大块空白。
  • 双指缩放保留，右下角倍率独立固定，文字和标签不会随画面放大。

BlurView 接入

依赖 Dimezis/BlurView version-3.2.0，JitPack 仓库仅允许该依赖组。相机使用 COMPATIBLE / TextureView 预览；原生 BlurTarget 仅包裹相机，BlurView 和倍率文字作为其同级覆盖层，避免模糊层采样自身。

Android 12（API 31）及以上使用实时背景模糊，半径 14，加随主题变化的半透明色与细边框。当前 V2458A Android 16 符合库的 TextureView 模糊要求。旧系统使用半透明标签，库文档明确不支持这些系统上的 TextureView 模糊。

相机内容缩放在 BlurTarget 内部进行，模糊目标与标签保持原尺寸；离开页面时释放预览父容器，避免返回页面重新挂载时出现已有父 View 的异常。未引入整屏截图或持续 Bitmap 采样来制作模糊。
