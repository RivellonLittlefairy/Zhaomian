网络状态权限修复

用户新日志显示 MediaPipe / DataTransport 的统计任务调度缺少 ACCESS_NETWORK_STATE；日志后续识别与两次保存成功。恢复该普通权限，无需运行时弹窗；仍不授予 INTERNET。此变更仅处理所示权限异常，不声称彻底禁用了 SDK 内部统计或所有后续上传尝试。按照用户此前要求，没有重新安装或进行修复版设备回归。

  • 重试相机：key(preview) 确保 AndroidView 使用当前显示的 PreviewView。
  • 普通文件扫描等待初始化结束；临时文件只在首次初始化清理。旧扫描不覆盖同时完成的新图片。

实施决定与边界

  • 使用 Compose、单 app 模块、现有包名。无 Git 仓库，未自动初始化或提交；HTML 记录代替 Git 技能进度脚本。
  • app 级有限保存任务在离页后收尾；相机与推理随前台监测会话停止。
  • 低于 4 MiB 可用空间暂停保存，仍处理真实写入 ENOSPC；不自动删图。
  • 目标机实测为 4 KB 页；MediaPipe 0.10.21 的 16 KB 页兼容性尚未验证，公开发布前需处理。
  • 模型具体分发许可、release 签名及非目标设备适配不作为本次私人调试 APK 已验证事项。
